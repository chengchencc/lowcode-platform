# 演示脚本（10 分钟）

> **给谁看**：准备试用/验收这套系统的同事。
> **怎么用**：照着走一遍即可，每一步都写了「该看到什么」——
> 看不到就是问题，不是「大概我点错了」。

## 0. 准备

Windows（cmd / PowerShell，不经过 WSL）：

```bat
rem 首次
scripts\setup.cmd

rem 终端 1 / 终端 2
scripts\dev-backend.cmd
scripts\dev-frontend.cmd
```

Git Bash / Linux / macOS：

```bash
bash scripts/setup.sh          # 首次
bash scripts/dev-backend.sh    # 终端 1
bash scripts/dev-frontend.sh   # 终端 2
```

打开 http://localhost:5173（用 `localhost`，不要用 `127.0.0.1` —— Vite 在 Windows 上绑的是 IPv6）。

账号（首启自动创建，幂等）：

| 账号 | 密码 | 角色 | 用途 |
|---|---|---|---|
| `admin` | `admin123456` | 平台管理员 | 组织管理、全部实例、终止、追加字段 |
| 张三 `zhangsan` | `demo123456` | 普通用户 | 发起人 |
| 李四 `lisi` | `demo123456` | 技术部主管 | 直属上级审批 |
| 王五 `wangwu` | `demo123456` | 财务 | 财务审批 / 核销 |
| 赵六 `zhaoliu` | `demo123456` | 设计者 | 演示表单/流程配置器 |

> 后四个默认**不开**（密码公开）。要演示审批链路，先在 `backend/.env` 里
> 打开 `SEED_DEMO_ACCOUNTS=true` 并重启后端；或者自己建号、把某人设为部门主管。

首启还预置了**示例流程库**（请假申请、费用报销），登录即可在「发起中心」看到。

## 1. 场景一：请假（顺序审批 + 条件分支 + 公式字段）

用**张三**登录。

1. **发起中心** → 卡片「请假申请」→ 发起
   - 填：假别=年假、开始 2026-10-01、结束 2026-10-06、事由=旅行
   - **看**：天数自动变成 5（公式字段，只读）
2. 提交 → 跳到详情页
   - **看**：状态「审批中」，进度条停在「直属上级审批」，右上角没有处理按钮（你不是处理人）
   - **看**：审批进度里能选出「按天数分流」的两个分支
3. 退出，用**李四**（技术部主管）登录 → 工作台「待办」
   - **看**：一条「请假 5 天」，角标有数字
4. 打开 → 同意（意见选填）
   - **看**：天数 > 3 → 走到「分管领导审批」（示例流程里指派给**平台管理员**）
5. 用 **admin** 登录 → 同意
   - **看**：发起人张三收到「已通过」通知；实例详情显示「已通过」
   - **看**：李四、管理员在进度条上各有一条完成记录；点时间线的「详情 → 查看当时的表单快照」能回放当时的数据

变体：天数填 2 → 第 4 步之后直接通过（条件分支的 else 分支），不经过分管领导。

## 2. 场景二：报销（并行会签 + 抄送 + 字段累积 + 驳回重提 + 追加字段）

用**张三**发起「费用报销」。

1. **填单**：事由=出差报销、费用类别=差旅 → 费用明细=机票、
   明细两行（机票 2×1000、住宿 1×1000）、上传一张发票
   - **看**：行内「小计」与「报销总额」自动算出 3000
   - **看**：费用明细（级联）的选项跟着「费用类别」变；把类别改成「办公」，
     已经选过的「机票」会被清空（不会留下对不上的组合）
2. **部门经理审批**：用**李四**（技术部主管）同意 —— 张三在技术部，所以「部门主管」解析到他
3. **财务双签（并行组）**：王五（会计）与 **admin**（财务负责人）**同时**收到待办
   - **看**：两人都同意才继续；任意一人驳回 → 整单打回
4. **驳回重提**：让王五驳回（意见写「发票不全，请补齐」）
   - **看**：张三详情页顶部直接显示驳回意见，并有「修改并重新提交」
   - 改一张字段再提交 → **看**：轮次变成「第 2 轮」，流程从李四重新开始
   - **看**：点时间线的「查看当时的表单快照」→ 出现「变更对照」卡片，
     基准默认是上一轮提交，能看出改了什么
5. **财务核销**：双签通过后，王五（财务）在「财务核销」节点填实际核销金额 + 发票号
   - **看**：这两个字段在申请阶段对张三**完全不可见**；只有这个节点能填
6. **追加字段（机制 C）**：用**admin** 打开这张还在跑的单子 → 右上角「追加字段」
   - 名称=合同编号、控件=单行文本、必填、可编辑节点=财务核销
   - **看**：王五刷新后多出一个必填字段；张三此时仍看不到
   - 王五填上「HT-2026-001」后提交
7. **抄送**：通过时财务会收到抄送（工作台「抄送给我」），抄送不阻塞流程
8. **归档可见**：通过后，张三打开详情
   - **看**：实际核销金额、发票号、合同编号**这时才可见**（归档视角，只读）
9. **导出**：详情页右上角「导出」拿到该单 CSV；「打印」可按浏览器另存为 PDF
   - admin 在「审批管理 → 实例管理」可看到运行中与已办结的全部单据；
     「归档台账」只列办结单据并支持**导出 CSV**（列含动态字段）

## 3. 设计者视角（可选，5 分钟）

用**赵六**（设计者）或 admin 登录。

- **审批管理 → 表单模板** → 新建/打开示例表单
  - 左侧控件面板拖字段；右侧配属性（必填、选项、公式、级联、校验、分区阶段）
  - **看**：改一处，预览立即跟着变
- **审批管理 → 流程模板** → 打开示例流程
  - 节点清单增删审批/条件/并行/抄送；右侧配审批人来源、字段权限矩阵（节点 × 字段）
  - **看**：发布时校验会拦住「审批人没配」「退回目标不合法」这类问题
- **组织管理**：用户 / 部门（树）/ 角色；**操作审计**：谁在什么时候改了什么，可导出

## 4. 常见问题

| 现象 | 原因 |
|---|---|
| 前端打开是空白/连不上后端 | 后端没起；用 `bash scripts/dev-backend.sh` 看端口占用提示 |
| 用 `127.0.0.1:5173` 打不开 | Vite 在 Windows 上绑 IPv6，请用 `localhost` |
| 审批人收到的是 admin 且标记「异常」 | 该部门没配主管 —— 去组织管理里指定，或直接用示例账号 |
| 提交报「必填项未填写」 | 服务端与前端用同一套规则（长度/范围/正则/选项/级联/行数），前端提示过但被绕过了 |
| 追加字段按钮不出现 | 需要管理员/设计者角色，且实例未归档 |
