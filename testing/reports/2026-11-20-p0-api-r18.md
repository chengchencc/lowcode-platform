## 3. G3 引擎不变量

- 新增 `testing/invariants/` 与 `scripts/invariants.sh`；默认 200 轮，`INVARIANT_ROUNDS` 可调。
- 随机生成顺序/条件/并行（all/any）流程，随机执行同意/驳回/重提；检查状态集合、任务与待办守恒、非运行态无阻塞待办、重复派单、快照 seq、actor/round、版本锁定。
- 覆盖率断言：并行、条件、驳回、重提、all/any 均实际发生过。
- 本机 200 轮约 12–15 秒；nightly 可提升到 2,000 轮。

## 4. 跳过 / 待确认

| 项 | 原因 |
|---|---|
| 双会话提交、同一任务并发处理 | SQLite 无行锁，500 属测试环境限制；已在 MySQL-only 分支，nightly 验证 |
| 空分支是否必须阻断发布 | PRD 与当前校验器语义存在歧义（当前仅缺「否则」时告警），需产品确认 |
| 「孤儿节点」定义 | 当前 schema 为树形，未找到可构造的孤儿形态；待确认是否指不可达分支 |
| 会签组内转办 | 语义边界未确认（转给同组成员/重复派单），暂不自动化 |
| 归档列序、打印 A4 | 人工/格式验收，随 UAT |
