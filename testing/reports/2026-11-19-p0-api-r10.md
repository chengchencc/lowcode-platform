## 2. 初跑失败与缺陷

### BUG-API-011（S2）检索索引同步用错模板 id

- 现象：自建流程提交后 `instance_field_values` 为空，业务字段筛选查不到数据；样例流程因 flow id 恰好等于 form id 未暴露。
- 根因：`sync_instance_index` 用 `instance.flow_template_id` 去查检索配置，而配置表按 `form_template_id` 存。
- 修复：先通过 FlowTemplate 解析 `form_template_id`，再加载配置。
- 回归：`test_search.py` / `test_search_operators.py` 恢复通过。

### BUG-API-012（S2）草稿保存接受 hidden/只读字段值

- 现象：创建草稿时注入 hidden 字段值，提交后仍落库（FORM-03 失败）。
- 根因：`create_draft` 直接使用客户端 data，没有按发起节点权限过滤；`update_draft` 已过滤，创建草稿漏了。
- 修复：创建草稿时复用发起节点权限 + `apply_field_patch`，只吸收可编辑字段。
- 回归：伪造 hidden/只读值不再进入 `current_data`。
