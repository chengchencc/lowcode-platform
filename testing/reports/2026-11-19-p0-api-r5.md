## 2. 初跑失败与缺陷

### BUG-API-008（S2）运行中快照多渠道泄露 hidden 字段

- 用例：`test_snapshots.py::test_running_snapshot_hides_supplement_from_initiator`
- 现象：
  1. `render?snapshot_id=` 使用归档视角，返回 hidden 字段的 key/值；
  2. `GET /snapshots/{sid}` 直接返回快照原始 `data`；
  3. `GET /timeline` / render 的 `actions.changed_fields` 带出 hidden 字段旧值/新值；
  4. `snapshots/diff` 直接返回差异行。
- 根因：
  - `render_service` 把“看快照”等同于“终态归档”，统一用 `resolve_view_permissions`；
  - 独立快照接口和时间线接口绕过了 render 的查看者裁剪；
  - 快照对照没有按查看者权限过滤。
- 修复：
  - 运行中快照按查看者当前权限求值；仅终态才用归档视角；
  - 新增 `view_filter.filter_actions`，时间线与 render 的 `actions.changed_fields` 按可见字段过滤；
  - 独立快照接口复用 render 的 values/ext_fields；
  - 快照对照按 render 的权限表过滤差异行。
