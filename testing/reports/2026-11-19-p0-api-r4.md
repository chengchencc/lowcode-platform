## 1. 本批新增能力

在 `testing/api/support/factories.py` 增加了一个**自建表单/流程工厂**：

- `simple_form_schema()`：一个文本字段 + 一个数字字段的最小表单。
- `create_form_and_publish()`：通过真实 API 建表单 → 发布版本。
- `create_flow_and_publish()`：建流程 → 写入 definition → 发布。
- definition 构造器：`dept_manager_chain_definition`、`parallel_any_definition`、`parallel_return_definition`、`sequential_definition`。

这让后续用例不再只能依赖种子流程，可以按需构造两级审批、或签、并行退回等场景。
