## 2. 失败与缺陷

### BUG-API-001（S2）hidden 字段的 key/标签仍在 API 响应中出现

- **对应用例**：
  - `test_initiate.py::test_reimburse_start_options_does_not_expose_hidden_keys`
  - `test_permissions.py::test_hidden_keys_should_not_be_in_running_render`
- **期望（D-04）**：运行中无权限视角不应拿到 hidden 字段的 key、标签、值；只下发可见字段的 schema。
- **实际**：
  - `GET /instances/start-options/{reimburse_flow}` 的 `schema_data` 含 `actualAmount`、`invoiceNo`，`permissions` 也含这两个 key。
  - `GET /instances/{id}/render` 在发起人视角同样含这两个 key。
  - **值没有泄露**（`values` 中只有申请区字段）；泄露的是字段 key/标签与权限项。
- **影响**：违反已确认的 D-04；前端虽然隐藏了字段，但 API 调用方可以推断补充字段的存在与名称。
- **建议**：在 start-options/render 的序列化边界按 `permissions.visible` 过滤 `schema_data`、`permissions`、`base_permissions`、`values`、`auto_fill_values`、`default_values`；同时过滤引用 hidden 字段的 `form_rules`，避免通过规则 key 旁路泄露。
- **回归**：保留上述两条测试，修复后应转绿。

### BUG-API-002（S2）设计者仍能拿到管理员首页概览

- **对应用例**：`test_permissions.py::test_designer_dashboard_has_no_admin_block`
- **期望（D-02）**：设计者只看个人工作台，`/dashboard/overview` 的 `admin` 为 `null`。
- **实际**：设计者 `zhaoliu` 调用 `/dashboard/overview` 返回了完整的 `admin` 区块（运行中数、今日提交、待办积压、流程分布）。
- **影响**：设计者可见全组织审批数据的聚合，违反 PRD §2 / D-02。
- **建议**：`dashboard_service` 的 admin 区块条件从 `is_designer(user)` 改为 `is_admin(user)`；前端首页按 `admin=null` 自然隐藏。
- **回归**：保留该测试，修复后应转绿。

## 3. 语义澄清（不是缺陷）

- `TaskRow.group_member_count` 当前语义是“**当前用户在同一会签组里的待办条数**”，前端标签为“同组 N 条”，不是组内总人数。测试已按此口径调整，不列为缺陷。
- `/tasks/mine` 返回 `InstanceOut` 分页（主键 `id`），不是 `TaskRow`（`instance_id`）；测试已修正。
