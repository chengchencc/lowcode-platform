## 2. 实现说明

- 造数统一走 API 工厂（`fixtures/factories.ts`）：自建表单/流程并真实发布，不直接改库。
- 关键交互走真实页面：发起、草稿续填、同意/驳回/退回、转办、追加字段、导出、消息已读。
- 每条用例同时断言界面可见结果与后端副作用（`render` / `todo` / 导出文件内容）。
- 为避免 antd 控件内部结构变化，定位优先 `getByRole` / `getByPlaceholder` / `getByTestId`；仅为日期面板与文件下载使用少量第三方内部类。
- 发起中心补了 `data-testid="flow-card"` / `data-testid="draft-item"`，避免草稿与流程同名时选择器歧义。
