示例数据走真实发布校验；不要直接改库造非法定义。

## 4. E2E 自建数据

P0 旅程需要的表单/流程尽量由测试通过 API 工厂创建，而不是只依赖种子：

- 所有名称带运行前缀：`E2E-<runId>-`。
- 每次套件启动前重置库；测试内不依赖执行顺序。
- 共享同一实例的多角色用例用 `test.describe.serial`。
- 附件统一放 `testing/.runtime/e2e/storage/`，跑完可整体删除。

## 5. 重置

```bash
bash testing/scripts/e2e-reset.sh
```

动作：删除 `testing/.runtime/e2e/` → 迁移 → 种子 → 输出账号表到 `testing/.runtime/e2e/accounts.md`。

**禁止**把 `DATABASE_URL` 指向开发库 `backend/flowform.db` 或任何生产库。
